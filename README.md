# chase.lol - obb editor

A lightweight, open-source Windows tool for browsing and editing Android APKs, OBB archives, and Unity assets.

## Features

- Browse archive contents with a file-tree interface.
- Inspect and preview supported assets.
- Work with Unity asset files.
- Open and modify Android APK files.
- Rebuild modified APKs for further testing.
- Simple desktop interface focused on ease of use.

## Built With

- C#
- .NET
- Avalonia UI

## Getting Started

1. Download or clone this repository.
2. Install the required .NET SDK.
3. Open the solution in Visual Studio or Visual Studio Code.
4. Build the project in Release configuration.

You can also use the included `build-release.bat` script on Windows.

## Open Source

This project is intended to make APK and Unity asset editing more accessible. Contributions, bug reports, and suggestions are welcome.

**Note:** Supported formats and features depend on the current implementation. Some operations may require additional tools.
